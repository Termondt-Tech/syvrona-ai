Prompt Builder: Prompts & Chains

Syvrona’s Prompt Builder lets you create, organize, and reuse your best prompts—or link them into powerful, multi-step chains to supercharge your workflow.

Prompts vs. Chains

  • Prompt: A reusable instruction, template, or question you can use as a starting point for any chat session.
    You can run a prompt directly, no chain required.
  • Chain: A step-by-step workflow made by connecting multiple prompts. Run the whole sequence at once—Syvrona will step through each prompt in your chain, in order.

Main Features

  • Create, Edit, and Organize Prompts: Save your best prompts with clear titles, descriptions, and tags.
  • Run Prompts Instantly: Start a chat or project from any prompt with one click—no need to add to a chain.
  • Build & Run Chains: Drag and drop prompts into a chain for multi-step automation. Reorder, remove, or reuse prompts anytime.
  • Tagging & Search: Use tags to organize and quickly find prompts or chains—even in large libraries.
  • “Create and Add Another”: Quickly add multiple prompts or chain steps without leaving the page.

How to Use Prompt Builder

  1. Go to Prompt Builder from the navigation menu.
  2. To create a new prompt: Click “+ Create New Prompt”, enter your prompt details, and save.
    You can add more prompts quickly using “Create and Add Another.”
  3. To create a chain:
    Click “+ Create New Chain”, give it a title, then drag prompts from your library into the chain order you want.
  4. To run a prompt or chain:
    Click “Use” (for prompts) or “Run” (for chains). You’ll be taken to a page where you can add optional context, choose your preferred AI model, and launch directly into chat.
  5. Tagging:
    Add tags as you create or edit prompts and chains. Use the tag bar for quick entry. You can search and filter by tag any time.

Frequently Asked Questions

Can I run an individual prompt inside a chain?
No. Running a chain always executes all steps in the chain, in order. To run just one prompt, use it directly from the Prompt Builder.
Can I reuse prompts in multiple chains?
Yes! Any prompt in your library can be added to as many chains as you like.
Can I rename or delete a tag?
Not yet—currently, you can only remove tags from prompts or chains. (Tag renaming and deletion are on our roadmap.)
Do I have to create chains to use the Prompt Builder?
No. Prompts can be used by themselves or grouped into chains, whichever fits your workflow best.
