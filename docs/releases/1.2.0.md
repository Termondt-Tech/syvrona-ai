# [1.2.0] - 2024-06-24

## Overview

This release delivers the initial private support ticketing system for subscribed users and admins, improved navigation, and a complete transactional email notification flow for ticketing activity. The release also introduces structural improvements to the navigation bar, better grouping of AI features, and robust role-based access to ticketing and admin controls.

## Enhancements

- **Support Ticketing System (MVP)**
  - Subscribed users can submit private support tickets and view the full conversation with staff/admins.
  - Admin dashboard for listing, viewing, and responding to all support tickets.
  - Each ticket maintains a status (`open`, `pending`, `resolved`, `closed`), settable by admins.
  - Ticket and message records are protected by appropriate access controls.

- **Support Ticket Conversation Threads**
  - Both users and staff can reply to tickets (unless closed).
  - All replies and original tickets are timestamped and attributed to sender type.
  - Robust handling for deleted users: shows “[deleted user #ID]” as appropriate.

- **Transactional Email Notifications**
  - Automated email alerts for every new ticket or new user message (sent to `info@termondttech.com`).
  - Users receive an email when staff replies to their ticket, including a direct link to view/reply in the portal.
  - HTML and plain text email templates styled with Syvrona branding.
  - Outbound email sending powered by Mailgun with robust error handling.
  - All email helper functions consolidated in a dedicated `email_utils.py` module.

- **Navigation & UX Improvements**
  - Logo in navbar now functions as the sole “Home” link (removes redundant “Home” nav item).
  - All AI-related features (“Chat”, “Conversations”, “Tags”) grouped under an “AI Assistant” dropdown.
  - “Support”, “Admin”, and “Profile” sections refactored as dropdown menus for clarity and scalability.
  - Fully responsive menu: dropdowns on desktop, accordions in hamburger menu for mobile.
  - CSS/JS updated to support dropdown interactions without breaking existing layout.
  - Accessibility enhancements for dropdown buttons (tabindex, focus).

- **Developer/Code Quality Enhancements**
  - Dedicated email notification helpers in `email_utils.py` for maintainability.
  - Email templates organized under `templates/emails/`.
  - All new features respect role-based access (user, admin).
  - Routes, forms, and models refactored for readability and extensibility.

## Database Schema Changes

- **New Table:** `ticket`
  - Columns: `id`, `user_id` (FK), `type`, `subject`, `status`, `created_at`, `closed_at`, `last_updated`
  - Foreign key: `user_id` references `user.id` (CASCADE on delete)
- **New Table:** `ticket_message`
  - Columns: `id`, `ticket_id` (FK), `sender_id` (FK, nullable), `sender_type`, `body`, `created_at`
  - Foreign key: `ticket_id` references `ticket.id` (CASCADE on delete)
  - Foreign key: `sender_id` references `user.id` (nullable, supports orphan messages)

- **Migration Required:**
  - Apply migrations to create both new tables and foreign key constraints.
  - No changes to existing tables; schema addition is non-breaking.

## Notable Bugfixes

- Fixed: Ticket message section did not display due to missing relationship on `Ticket.user`; now robust against deleted users.
- Fixed: Admin ticket detail page now properly handles both status updates and staff replies in a single view.

## Upgrade/Migration Notes

- **You must apply DB migrations to create the `ticket` and `ticket_message` tables before deploying this release.**
- Deploy new templates in `templates/emails/` and add `email_utils.py`.
- Update environment configuration with `MAILGUN_DOMAIN` and `MAILGUN_API_KEY` if not already set.
