# [1.1.2] - 2025-06-16

## Enhancements

- Message Tagging:
  - Users can now add custom tags to individual messages in any conversation.
  - Tags help organize, filter, and quickly find important information later.
- My Tags Page:
  - New “My Tags” section in the main navigation lists all your tags, including usage counts and quick links to tagged messages.
- Tagged Messages View:
  - Click any tag to instantly see all messages associated with it, across all your conversations.
- Message Details View:
  - View any individual message—including full content, timestamp, tags, and quick actions to jump to the message in its conversation or see other messages with the same tag.
- Improved Guidance for New Users:
  - If you have no tags yet, the “My Tags” page provides simple, clear instructions for getting started with message tagging.

## Changed

- Keyboard Navigation:
  - Improved up/down arrow support when using tag autocomplete in conversation and chat views.
- Consistent Tag UI:
  - Tag pills, add/remove buttons, and suggestion dropdowns are visually refined and consistent throughout the app.
- Auto-Scroll and Highlight:
  - When jumping to a message from a tag, the conversation view scrolls directly to the message and highlights it briefly for easy reference.

## Fixed

- Accurate Timestamps:
  - Fixed an issue where new messages or conversations could receive the same timestamp due to how default values were set in the database model.

## Database

- No database migration required for this release.
  - All tag-related features and timestamp fixes were implemented at the application code level.
  - No changes to table structures, new columns, or altered indexes in this release.
- Deployment Note:
  - Simply deploy code changes as usual—no need to run `flask db migrate` or `flask db upgrade` for this version.

## How to Use

- To add a tag: Click the "+" next to any message, type your tag, and hit Enter.
- To view tags: Visit “My Tags” in the main navigation.
- To see all messages for a tag: Click any tag on “My Tags” or inside a chat.
- To jump to a message: From “Tagged Messages,” click the message for more options, including a direct link to the original conversation.
