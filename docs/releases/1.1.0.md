# [1.1.0] - 2025-05-28

## Summary

Major architectural upgrade introducing multi-provider, multi-model support with real-time streaming across both OpenAI and Anthropic models. This release lays foundational work for future feature expansions including response formatting, improved streaming UX, and additional providers.

## Enhancements

### Multi-Model Architecture

- Introduced dynamic model registry for unified provider/model management.
- Fully supports OpenAI and Anthropic models.
- Dropdown model selector added to web UI for easy model switching.
- Simplifies future model additions by updating **model_registry.py** only.

### Supported Models

- **OpenAI Models**
- gpt-4.1
- gpt-4.1-mini
- gpt-4o
- gpt-4o-mini
- gpt-4.1-nano
- o3
- o3-mini
- o4-mini
- gpt-4.5
- gpt-3.5-turbo
- **Anthropic Models**
- claude-sonnet-4-20250514
- claude-opus-4-20250514
- claude-3-7-sonnet-20250219
- claude-3-5-sonnet-20241022
- claude-3-5-haiku-20241022
- claude-3-haiku-20240307
- claude-3-opus-20240229

## Anthropic Claude 3 API Integration

- Full streaming support using `/v1/messages` API.
- Correct handling of system prompts via `system` parameter.
- Properly handles Anthropic `TextDelta` streaming chunks.

## OpenAI Streaming Provider Standardization

- Unified streaming logic across both providers.
- Correct chunk parsing via OpenAI `v1/chat/completions` endpoint.

## Persistence & Message Storage Refactor

- Resolved duplicate user/assistant message insertion.
- Centralized message creation inside core `AIStreamer` class.
- Each conversation round now inserts one user message and one assistant message.

## Centralized Provider Interface

- Both providers now implement consistent `stream_response()` signatures.
- Simplifies handler logic and greatly improves maintainability.

## New Configuration (Environment Variables)

- `ANTHROPIC_API_KEY` introduced for Anthropic provider authentication.

## Internal Engineering Changes

- Unified error handling between providers.
- Expanded logging for better debugging across both OpenAI and Anthropic calls.
- Moved conversation context management to central streaming layer.
- Simplified backend logic for supporting new models going forward.
- Improved HTTP-level logging to assist with API troubleshooting.

## UI Enhancements

- Model selector dropdown fully functional.
- User can switch between OpenAI and Anthropic models seamlessly before starting a conversation.

## Known Limitation

- Streamed output is delivered raw (Markdown rendering improvements coming in future version).
- No per-user model permissioning yet (global model access across all users).

## Next Planned Work

- Streaming response formatting layer (Markdown rendering, paragraph control, etc.).
- Provider response abstraction for universal display rendering.
- Basic streaming UI polish for smoother user experience.
- Conversation export improvements.
