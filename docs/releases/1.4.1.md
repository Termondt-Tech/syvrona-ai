# [1.4.1] - 2024-07-08

## Enhancements

- **Universal Responsive Table Component**
  - Migrated prompt, chain, conversation, and support ticket tables to a universal, responsive `app-table` style.
  - Added horizontal scrolling, mobile “card” view, and consistent header/action alignment.
  - Centralized empty-state messaging and tag-list rendering for all list pages.
- **Consistent Pagination & Page Size Controls**
  - Standardized pagination controls and page-size dropdowns for prompt and chain lists.
  - Retained search and filter queries during pagination.
  - Unified UI and navigation logic across all major tables.
- **Improved Form & Action Layout**
  - Unified form widths, alignment, and spacing for create/edit forms.
  - Aligned secondary navigation and fixed centering/shifting inconsistencies.
  - Eliminated duplicated `.btn` and form styles, consolidating into shared files (`buttons.css`, `forms.css`).
- **Accessibility & Code Quality**
  - Moved `.visually-hidden` and `.no-content-message` to `base.css` for reusability and clarity.
  - Removed inline styles from templates, favoring reusable CSS classes.
  - Deduplicated CSS across table, prompt, chain, and button styles.
- **Bulk Data Entry Enhancements**
  - Added “Create and Add Another” options to both Prompt and Prompt Chain creation forms.
  - Improved workflow for manual/bulk entry and faster UI testing.
- **Prompt Chain Builder Enhancements**
  - Fixed and enabled drag-and-drop reordering of steps in the chain builder using SortableJS.
  - Adjusted chain builder prompt selection panel width for usability.
  - Enhanced visual feedback and hinting for step order and drag/keyboard reordering.
- **General UI/UX Polish**
  - Unified empty and error states across all list views.
  - Standardized action button appearance (Edit/Delete/Run/Use) and container alignment.
  - Improved support for batch operations and better mobile/tablet usability.
- **Unified Tag Pill & Badge Styling**
  - Standardized the appearance and layout of all tag pills and badges across the dashboard and tags pages.
  - Centralized all tag-related CSS in `tags.css` for maintainability and consistency.
  - Improved tag responsiveness, accessibility, and type-based color cues for better visual clarity.
- **Accurate Code & Template Display in Chat**
  - Fixed display of user-submitted code and template content in chat:
    - User messages containing raw code, Flask/Jinja templates, or markdown now render in a dedicated code block.
  - Prevented double-escaping and HTML entity leakage by performing all necessary escaping in JavaScript with `textContent`, ensuring code and special syntax always appear exactly as entered.
  - Assistant messages continue to be rendered with full markdown support.

## Bugfixes

- Fixed prompt chain drag-and-drop not working on chain creation page.
- Fixed panel alignment issues on forms and support ticket views.
- Resolved table action button inconsistencies (e.g., underline on links).
- Ensured all no-content messages appear and align correctly.
- Fixed mangled formatting of user code/templates in chat—user messages are now faithfully rendered as preformatted code blocks without HTML entity leakage.

## Developer Notes

- Use `responsive-table.css` for all new and existing data tables.
- Move any table or form-specific CSS to centralized, shared files to reduce duplication.
- Use the shared `.no-content-message` and `.visually-hidden` classes for accessibility and consistency.
- Use the updated pagination block (see prompt list) as the canonical example for all paginated tables.
- For bulk data entry, use the “Create and Add Another” pattern as shown in prompt and chain create forms.
- For chain builder drag-and-drop, ensure `SortableJS` is included and properly initialized.
