# Syvrona Chat: UI/UX Improvements & Bug Fixes

## Version: v1.4.5

### Release Date: 2025-07-18

---

## ✨ New Features & Enhancements

- **Mobile-Optimized Chat Layout:**  
  Improved chat container and input row responsiveness for a seamless mobile experience. Elements resize and adjust for all device widths.

- **Persistent, Pinned Chat Input:**  
  Chat input and model selector are always visible and accessible at the bottom, eliminating the need to scroll to reply.

- **Auto-Scrolling & Focus:**  
  Conversation always auto-scrolls to the latest message, with the cursor placed in the input area after each message, prompt, or chain load.

- **Auto-Expanding Chat Input:**  
  The textarea automatically expands as you type, accommodating multi-line input without manual resizing.

- **Send Button Loading State:**  
  The “Send” button is disabled and displays a spinner while the assistant is responding, preventing duplicate submissions and providing clear feedback.

- **Toast Notifications:**  
  Non-intrusive toast notifications provide feedback on errors (e.g., failed tag actions or network issues), and can be dismissed by click.  
  - All error alerts are now handled by toasts, replacing intrusive `alert()` dialogs.

- **Accessible Toast Area:**  
  Toasts now include proper `role="status"` and `aria-live="polite"` for improved screen reader support.

- **Improved Markdown/Code Rendering:**  
  Assistant and user messages are rendered using marked.js, displaying markdown and code blocks with improved styling.

- **Optimized Tag Management:**
  - Tag adding/removal is now more robust and uses event delegation for improved performance.
  - Tag input and suggestions UX improvements: inputs hide on blur, suggestions reset, and auto-completion navigation is smooth.

---

## 🛠 Bug Fixes

- **Input Field State Restoration:**  
  Fixed issues where the tag input could be left in an inconsistent state (e.g., showing previous characters after closing).

- **Send Button Enable/Disable:**  
  Fixed a bug where the Send button could become stuck in a disabled state after a failed request.

- **Error Handling Robustness:**  
  All fetch failures (for both tag and message actions) now show a toast instead of a silent failure or blocking alert.

- **Mobile Max Height Constraint:**  
  Improved chat container and suggestions dropdown to better respect mobile viewport constraints and avoid overflow.

- **Tag Suggestions UX:**  
  Suggestions dropdown no longer lingers after escape/blur, and suggestions do not overflow out of the viewport.

- **Markdown Rendering Consistency:**  
  Initial messages and dynamically loaded messages both render markdown consistently.

---

## 🧹 Code and Best Practice Improvements

- **Event Delegation:**  
  All dynamic tag events use event delegation, reducing the need for rebinding after DOM changes.

- **Single Source of Truth for Scroll Logic:**  
  Consolidated scroll-to-bottom logic to avoid UX inconsistencies.

- **Accessibility Improvements:**  
  Added `aria-labels` and accessible roles to the toast and form controls.

- **CSS Refactoring:**  
  - Improved media queries for better mobile scaling.
  - Unified chat container, input row, and button styles for a cleaner, more modern look.

- **Cleaner Error Handling and Notification Logic:**  
  All errors and important UX feedback routed through a single, reusable toast function.

---

## 🔎 Not Implemented (Consider for Future Releases)

- **Virtual Scrolling for Large Chats:**  
  Considered virtual scrolling (e.g., Clusterize.js) for very large conversations but deferred to a future release for simplicity.

- **Pagination for Message History:**  
  Not implemented to avoid UX friction.

---

## 🚀 How to Use

- **Start typing and hit Send.**  
- **Try adding/removing tags to any message using the + icon.**
- **All error notifications now appear as dismissible toasts.**
