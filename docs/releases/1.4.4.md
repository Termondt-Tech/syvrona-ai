# [1.4.4] - 2025-07-17

## Enhacements

- Rename and delete tags directly from the my-tags page (#67)
  - Add orphaned tags to my-tags page
  - Icons added to the tag pill; custom modal for actions

## Arctitedcture

- Architectural refactoring (#83)
  - Renamed `app/handler` to `app/services` ([Flask best practice](docs/best_practices.md))
  - Introduced `tags` Blueprint for separation of concerns
  - Moved `/my-tags` and `/tags` routes from `chat.py` to `tags.py`
  - Updated all references to `/my-tags` and `/tags`
- Migrate Syvrona wiki to GitHub (#85)

## Fixed

- CSRF token expired error on `/answer` (#82)
  - Added `WTF_CSRF_ENABLED` and `WTF_CSRF_TIME_LIMIT` to `config.py` and `.env`

## Developer Notes

- Tag functionality for messages remains in `chat.py`
- `create_tag` will be moved from `chat.py` to `tags.py` in a future release

## Upgrade Instructions

- Add new variables to `.env`:
WTF_CSRF_TIME_LIMIT=86400 # 24 hours
WTF_CSRF_ENABLED=true

- Follow standard deployment steps ([Deployment SOP](docs/deployment.md))

## No Database Migrations in this Release (1.4.4)

## Known Issues (1.4.4)

- CSRF token expiration may still occur. If so, fetch call to `/answer` will return a 400 Bad Request with: "The CSRF token has expired."
