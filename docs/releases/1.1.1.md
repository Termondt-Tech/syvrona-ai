# [1.1.1] - 2025-05-29

**Release Version:** v1.1.1  
**Feature:** Stripe Recurring Subscription Billing  
**Release Date:** 2025-05-29  
**Product:** Syvrona (Flask SaaS Web App)

## Overview

This release adds full Stripe subscription billing with self-service management for Syvrona users. Customers can select between Free, Pro Monthly, and Pro Yearly plans at signup. Subscriptions are managed via the Stripe Customer Portal, with upgrade, downgrade, and cancel supported.

## Enhancements

- Signup form with plan selection (Free, Pro Monthly, Pro Yearly)
- Seamless Stripe Checkout integration for recurring billing
- Stripe Customer Portal for users to manage payment method, upgrade/downgrade plan, or cancel subscription
- Secure webhooks handle subscription state and update user records in the database
- Environment-based configuration for all Stripe API keys and price IDs (no hardcoding)
- User profile page displays current subscription plan and status, with "Manage Subscription" button

## Testing in Development

- Use **Stripe’s Test Mode** for all development and local testing.
- **Test API keys:**
- In Stripe dashboard, enable ''View test data''.
- Use the ''Secret key'' (starts with ''sk_test...'') in your ''.env'' or ''.flaskenv'':

``` text
STRIPE_API_KEY=sk_test_xxx
STRIPE_WEBHOOK_SECRET=whsec_xxx
STRIPE_PRICE_ID_PRO_MONTHLY=price_xxx   # From your test product
STRIPE_PRICE_ID_PRO_YEARLY=price_xxx
```

- **Testing webhooks locally:**
- Install [Stripe CLI](https://github.com/stripe/stripe-cli).
- Start forwarding webhooks to your dev server:

``` bash
stripe listen --forward-to localhost:5001/stripe/webhook
```

- Use the webhook signing secret shown by Stripe CLI as ''STRIPE_WEBHOOK_SECRET''.
- **Test card numbers:**
- Use ''4242 4242 4242 4242'' (any future date, any CVC/ZIP).
- More test cards: [Stripe Test Cards](https://stripe.com/docs/testing#international-cards)
- **Test plan switching and cancellation:**  
- Use the Stripe Customer Portal in test mode to verify upgrade, downgrade, and cancel.
- **Test and live price IDs are separate!**  
- Always use the correct price ID for the current environment.

## Database Changes

- User model updated to include subscription fields:

1. stripe_customer_id
1. subscription_status
1. subscription_plan
1. subscription_start
1. subscription_end

- Alembic migration created and applied to add these columns.
- During production deployment, the following command must be run **inside the Docker container** to apply schema changes:

``` bash
docker exec -it <your_flask_container_name> flask db upgrade
```

- Confirm database schema is up to date before accepting live subscriptions.

## Environment Variable Reference

- STRIPE_API_KEY: Live secret key for API access
- STRIPE_WEBHOOK_SECRET: Live webhook signing secret
- STRIPE_PRICE_ID_PRO_MONTHLY: Price ID for Pro Monthly plan
- STRIPE_PRICE_ID_PRO_YEARLY: Price ID for Pro Yearly plan

## Webhook Event Handling

- **checkout.session.completed**: Payment success, can trigger onboarding logic
- **customer.subscription.created** / **.updated** / **.deleted**: Update user DB with status, plan, billing dates

## Known Limitations

- Price and product changes require both test and live updates in Stripe dashboard
- Webhook failures may delay subscription state changes—monitor logs for errors
- Portal plan switching only available if enabled in Stripe settings for each product

## Sample Code Snippet (Environment-Safe Plan Mapping)

``` Python
# In Flask route
import os

STRIPE_PRICE_IDS = {
    'pro_monthly': os.getenv('STRIPE_PRICE_ID_PRO_MONTHLY'),
    'pro_yearly': os.getenv('STRIPE_PRICE_ID_PRO_YEARLY'),
}
PRICE_LABELS = {
    STRIPE_PRICE_IDS['pro_monthly']: 'Pro Monthly ($9.99/mo)',
    STRIPE_PRICE_IDS['pro_yearly']: 'Pro Yearly ($99/year)',
    'free': 'Free',
}

# In webhook handler, reverse map price ID to logical plan code:
for plan_code, price_id in STRIPE_PRICE_IDS.items():
    if subscription['items']['data'][0]['price']['id'] == price_id:
        user.subscription_plan = plan_code
        break
else:
    user.subscription_plan = subscription['items']['data'][0]['price']['id']  # fallback
```
