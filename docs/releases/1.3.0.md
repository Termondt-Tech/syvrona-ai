# [1.3.0] - 2025-06-26

## Overview

This release delivers a robust user/admin notification system, a new user dashboard, notification detail view, pagination and filtering for key admin/user screens, UX and access control improvements, plus **two database migrations** to support notifications and ticket-message tagging.

## Enhancements

- **User Dashboard**
  - New dashboard at `/dashboard` is now the post-login landing page.
  - Cards for: Quick Start, Notifications, Recent Conversations, Recent Tags, Open Tickets, Account Status.
  - Responsive design fixes grid, vertical spacing, and button alignment.
  - Notifications and tags are previewed, with links to view full history.

- **End-User Notifications System**
  - User notification list `/notifications`:
    - Broadcast/system/targeted notifications for all users and per-user.
    - Visual distinction for unread, archived, and read notifications.
    - Truncated previews for long notifications; full “View” page for each notification.
    - Actions: mark as read, archive, archive all.
    - Pagination and filter by status (Read, Unread, Archived).
  - Notification badge shows correct unread count globally.

- **Notification Detail Page (User Side)**
  - Dedicated route for users to view full notification message.
  - Mark as read on open, ticket link shown if present.

- **Message Tagging (Advanced Tagging)**
  - Tag system now visible on dashboard and “My Tags” with usage count.
  - Pro-only feature per subscription logic.

- **Admin Notification Management**
  - List, create, and view notifications from `/admin/notifications`.
  - Audience and sender columns display name/email, not just ID.
  - Pagination, per-page selector, and filter by notification type (system, marketing, ticket).
  - “Create Notification” only allows linking a ticket if a user is selected (server-validated).
  - Form input is preserved on error.

- **Admin User Management**
  - User list supports pagination and per-page selection.
  - Filter by subscription status (matches Stripe API: active, incomplete, trialing, canceled, past_due, none).
  - Sort by joined date and last login, with clear indicators.

- **Subscription/Access UX**
  - If accessing a Pro-only feature, user is redirected directly to Subscribe page, not profile.
  - Subscribe page uses branded, responsive card layout; “Best Value” badge for yearly.
  - New `badge-none` CSS for unsubscribed users.

- **Flash Message Handling**
  - Fixed rare cases of stale flashes.
  - Flash messages now consistently show in-context and clear on navigation.

## Database Schema Changes

- **202406251001_add_notifications_table.py**
  - New table: `notification`
    - Fields: `id`, `sent_by`, `for_user_id`, `ticket_id`, `title`, `body`, `type`, `created_at`
    - Relationships: sender (admin), recipient (user), linked ticket

  - New table: `notification_read`
    - Fields: `id`, `notification_id`, `user_id`, `read_at`, `archived`
    - Unique constraint: (notification_id, user_id)

- **202406251002_add_message_tagging.py**
  - New table: `tag`
    - Fields: `id`, `name`, `user_id`
    - Unique constraint: (user_id, name)
  - New many-to-many table: `message_tags`
    - Fields: `message_id`, `tag_id` (composite PK)
    - Supports tagging of any message in a conversation

- **Migration instructions:**
  - Log into container and apply both Alembic migrations:

    ```bash
    docker exec -it syvrona-ai-web-1 bash
    flask db upgrade
    ```

## UI/Styling Changes

- Unified `admin.css`, `dashboard.css`, and `notifications.css` for table, badge, card, and button consistency.
- Notification badges, type badges, subscription badges (`badge-none`), and improved spacing for all cards and lists.
- Responsive grid for dashboard; fixes overflow/vertical stretching issues when content in cards varies.

## Code Quality, Decorators, and Best Practices

- Refactored all query logic to use SQLAlchemy idioms (`is None`, not `== None`; `if x`, not `== True`).
- All filtering (for open tickets, unread/archived notifications) done at the query level, not in Python lists.
- Fixed legacy use of deprecated `datetime.utcnow()`; now uses `datetime.now(timezone.utc)`.
- Form re-population after errors standardized across all admin create/edit views.
- Decorator for Pro-only features now always redirects to `/subscribe`.
- Flash messages never persist unexpectedly.

## Bugfixes and Cleanups

- Fixed: Notification unread count always in sync (was breaking if context_processor not called).
- Fixed: Notification list/table layout collapse on mobile and desktop.
- Fixed: Subscription badges misaligned with user status.
- Fixed: User/account info display for missing or malformed subscription data.
