## Security Enhancements

| Step                                                     | Code Snippet                                                         |
| -------------------------------------------------------- | -------------------------------------------------------------------- |
| Added new library to `requirements.txt` for CSRF support | `Flask-WTF==1.2.2`                                                   |
| Added CSRF token to every form post                      | `<input type="hidden" name="csrf_token" value="{{ csrf_token() }}">` |
| Made CSRF token available to JavaScript in `base.html`   | `<script>window.csrf_token = "{{ csrf_token() }}";</script>`         |
| Added CSRF token to every JS POST header                 | `"X-CSRF-Token": window.csrf_token`                                  |
