# [1.0.0] - 2925-05015

## Summary

This version marks the first production-ready milestone of Syvrona-AI, with stable conversational memory, a user-friendly UI, and proper data management.

## Enhancements

- Multi-message conversational memory
- Conversations and messages stored via SQLAlchemy
- Sessions track active conversation ID
- Initial prompt and reply now persist across session
- Resuming past conversations via `/conversation/<id>` route

## UI Enhancements

- `chat.html` updated:
- Uses `<div id="body">` for rendering
- Messages streamed with JavaScript and shown inline
- Prior messages rendered with Jinja from backend
- `conversations.html` added:
- Shows all user conversations
- Editable titles
- Links to resume or view
- Delete button added

## Database Changes

- New models: `Conversation`, `Message`
- Cascade delete enabled:
- `ondelete='CASCADE'` on foreign keys
- `cascade='all, delete-orphan'` in SQLAlchemy relationships

## Deployment Notes

- Production container failed due to missing `.env` → fixed by copying it over
- All migrations applied successfully via `flask db upgrade`

## Git & Versioning

- Milestone tagged as `v1.0.0` using:
    `git tag -a v1.0.0 -m "..."` with multi-line message
- Tag pushed to origin
- Option to turn into GitHub Release is open
