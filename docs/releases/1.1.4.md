# [1.1.4] - 2025-06-16

## Enhancements

- **7-Day Free Trial for Paid Plans**
  - Users can now sign up for a 7-day free trial on all paid subscription plans (Pro Monthly and Pro Yearly).
  - Free trial is seamlessly integrated with the Stripe subscription checkout flow.
  - Users are not charged until the end of their trial period and can cancel anytime before billing begins.
  - All UI components (registration, plan selection, confirmation screens) now clearly display the free trial period if enabled.

- **Feature Flag Architecture**
  - Introduced centralized feature flag system for dynamic feature management.
  - Free trial functionality is fully controlled by the `FREE_TRIAL_ENABLED` feature flag (environment/config driven).
  - The trial period length is configurable via the `FREE_TRIAL_DAYS` environment variable.

## Configuration

- New environment variables (add to your `.env` or deployment environment):
    FREE_TRIAL_ENABLED=true
    FREE_TRIAL_DAYS=7
- `FREE_TRIAL_ENABLED` – Controls whether the free trial is offered (`true` or `false`). Defaults to `false` if unset.
- `FREE_TRIAL_DAYS` – Number of days for the trial period (integer). Defaults to `0` if unset.
- When `FREE_TRIAL_ENABLED` is set to `false`, the free trial banner and logic are fully disabled in both UI and backend.

## Code Changes

- Added centralized feature flag access in `config.py` (or equivalent):
    FEATURE_FLAGS = {
        "FREE_TRIAL_ENABLED": (
            os.environ.get("FREE_TRIAL_ENABLED", "false").lower() == "true"
        ),
        "FREE_TRIAL_DAYS": int(os.environ.get("FREE_TRIAL_DAYS", 0)),
    }
- Updated Stripe subscription creation logic to dynamically include the `trial_period_days` parameter only when the free trial is enabled.
- Registration page UI updated to display free trial messaging only if feature flag is enabled and days > 0.
- Feature flag and trial duration are injected into templates and user flows for consistent behavior.

## Operations Notes

- Enabling/Disabling Free Trials: Set `FREE_TRIAL_ENABLED` in your environment to toggle the feature at any time. Restart the application after changing this variable.
- Changing Trial Length: Modify `FREE_TRIAL_DAYS` to update the free trial period. The change is effective for all new signups after deployment/restart.
- Monitoring & Testing: Test both states (`FREE_TRIAL_ENABLED=true` and `false`) to ensure the UI, backend, and Stripe integration behave as expected.
- Future Expansion: This feature flag pattern is now available for future feature rollouts and operational toggles.

## Database Changes

- No schema changes required for this release.

## Deployment Instructions

1. Pull the latest code and deploy to your environment.
2. Update environment variables as needed.
3. Restart the application to apply new configuration.
4. Verify signup flow in both free trial enabled and disabled states.
