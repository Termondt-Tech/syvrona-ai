# [1.1.3] - 2025-06-16

## Enhancements

- Implemented secure "Forgot Password" workflow:
  - Users can request a password reset link via email directly from the login page.
  - Reset links are one-time use, time-limited (1 hour), and cryptographically signed.
  - Users must enter and confirm a new password; passwords are securely hashed using PBKDF2.
- Added dedicated password reset and confirmation forms with improved UI/UX.
- Enhanced flash message system for clearer user feedback during the password reset process.
- HTML and plain text email templates for password reset, featuring Syvrona branding.

## Changed

- All email sending is now handled via Mailgun API integration (SMTP and Flask-Mail removed).
- All email and mail server configuration is now managed via environment variables for improved security and deployment flexibility.
- Login form UI updated: improved spacing for the "Forgot your password?" link.
- Standardized password hashing and confirmation flow across all authentication endpoints.

## Technical Notes

- Email sending uses direct Mailgun API calls, with configuration fully in `.env`.
- `.env` is now the single authoritative source for all runtime configuration and secrets.
- Deprecated usage of `.flaskenv` for runtime config in Dockerized environments.
- Includes both HTML and plain text email templates for improved deliverability and appearance.

## Security

- Password reset tokens expire after 1 hour for enhanced account protection.
- All secrets and mail credentials must be managed outside of source code (in `.env` or deployment environment).
- Password handling is explicit, consistent, and fully documented.

## Environment Variables

The following Mailgun-specific variables must be set in your `.env`:

- `MAILGUN_API_KEY=************************`
- `MAILGUN_DOMAIN=mg.syvrona.com`
- `MAILGUN_FROM_EMAIL=Syvrona AI <noreply@syvrona.com>`
